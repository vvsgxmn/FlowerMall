# 基于SpringBoot+Vue的鲜花商城系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

FlowerMall 是一款面向线上鲜花零售场景的电商交易平台，支持鲜花浏览选购、购物车结算、送达预约、贺卡定制、订单跟踪、退款维权与交易评价，并提供花语百科与私人花艺定制服务；普通顾客与管理员双端协同，适合毕设、课设与学习参考。

## 主要功能模块

- **用户认证模块**：支持普通顾客与管理员登录注册，按角色跳转商城前台/运营管理后台
- **商品交易模块**：鲜花分类浏览、送花场景筛选、关键词搜索、详情展示、收藏心愿单与带图评价
- **购物车订单模块**：购物车管理、收货地址、期望送达日期与时段预约、手写贺卡赠言定制、模拟支付下单
- **订单履约模块**：订单全生命周期跟踪、冷链物流轨迹模拟、确认收货、申请退款与后台审核
- **花语百科模块**：花艺养护技巧、花语寓意文章浏览与商城活动公告阅读
- **私人定制模块**：婚礼/商务/大型花束等定制需求提交，花艺师留言回复跟进
- **后台运营模块**：数据看板可视化、分类与商品管理、订单配花发货、评价审核、轮播海报、资讯发布与用户管理

## 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis-Plus 3.5.3 + JWT + Lombok
- **前端**：Vue 3 + Vue Router + Pinia + Element Plus + ECharts + Vite 5
- **数据库**：MySQL 8.0
